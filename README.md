Daily Reflection Tree — Deterministic Reflection System
What this is

This project is a deterministic reflection agent that guides a user through a structured end-of-day reflection.

The system walks the user across three psychological axes:

Agency (Locus): Did I act, or did things happen to me?
Contribution (Orientation): What did I give vs expect?
Perspective (Radius): Did I stay self-focused or consider others?

The core idea is simple:

Reflection can be designed as a system — not generated at runtime.
